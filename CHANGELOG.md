# Changelog

## 1.0.4 — 2026-07-27

### Добавлено
- MPR в режиме пациента (RadiAnt-style LPS) с переключателем **Пациент / Стек**
- Режимы MPR: 1 плоскость / 4 плоскости, отдельная панель инструментов у вьюпорта
- Геометрия тома по IOP/IPP (`VolumeGeometry`) для корректных реформатов

### Исправлено
- Аксиал в режиме пациента больше не крутится относительно серии (учёт IOP, правильный row→X / column→Y)
- Сагитал и коронал стоят вертикально: Superior сверху
- Учтён spacing (мм) для пропорций коронала/сагитала
- Стабильность MPR: меньше OOM при скролле, ErrorBoundary, безопасный fallback Canvas/WebGL

### Изменено
- Версия приложения **1.0.4**

## 1.0.3 — 2026-07-26

### Исправлено
- Ужесточён allowlist путей: запрет широких корней (`/`, home и т.п.), drop файла больше не открывает всю родительскую папку
- Временные каталоги только явно зарегистрированные (`registerSessionTemp`), без эвристики `slice-*`
- C-MOVE Store SCP слушает `127.0.0.1` и проверяет Calling/Called AE
- Блокировка нежелательной навигации и `window.open`
- `media:list` больше не добавляет тома в allowlist; доступ после `media:open`
- `openExternal` только для хостов GitHub Releases/Downloads
- Валидация PACS-подключения в main-процессе
- Восстановлены пути `userData` для профилей PACS и границ окна (права `0o600` для профилей)
- Лимит размера ZIP 512 MB (защита от OOM)

### Изменено
- CSP задаётся только через Electron session headers
- Версия приложения **1.0.3**

## 1.0.2 — 2026-07-25

### Исправлено
- Проверка обновлений больше не падает из‑за CORS: запрос к GitHub идёт через main-процесс Electron
- При актуальной версии не показывается всплывающее окно — рядом с номером версии зелёная галочка с подсказкой
- «Лог обновлений» скрыт, пока нет ошибок проверки

### Изменено
- Версия приложения **1.0.2**

## 1.0.1 — 2026-07-25

### Добавлено
- Сборка Windows папкой (`win-unpacked` / zip) через GitHub Actions
- Отображение версии и проверка обновлений через GitHub
- Просмотр «что нового» при доступном обновлении
- Лог обновлений (те же правила хранения, что у лога ошибок)
- Браузер DICOM-тегов, эллиптический ROI, инверсия/отражение, decode workers
- Нативное меню, горячие клавиши, компактная панель, Icon.ico

### Изменено
- Версия приложения **1.0.1**
- Загрузка серий: сначала метаданные, Int16 LRU-кэш пикселей для больших серий

### Исправлено
- Подготовка артефакта релизов `Slice-*-win-x64.zip`
